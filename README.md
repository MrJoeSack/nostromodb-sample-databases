# nostromodb-sample-databases

Synthetic JSON sample datasets for trying out [NostromoDB](https://nostromodb.io/).

| Dataset | Description |
| --- | --- |
| [`semantic-shores-json`](./semantic-shores-json) | Real-estate listings, plus agents and search phrases. |

Newline-delimited JSON. All data is synthetic and generated by the included
scripts. Sizes are small for now and can be regenerated larger.
