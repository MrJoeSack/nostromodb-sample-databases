# nostromodb-sample-databases

Sample datasets for testing and demonstrating [NostromoDB](https://nostromodb.io/),
an in-process JSON OLAP column-store with a SQL-like front end and natural
nested sub-field access.

The datasets here are JSON-native (newline-delimited JSON) and are designed to
exercise the things NostromoDB is built for: mostly regular, columnar data
(the case it should shred and scan fastest), plus deliberate nesting,
variable-length arrays, sparse fields, and mixed-type fields to probe its
claim of not "falling off a cliff" on irregular JSON.

## Datasets

| Dataset | Records | Description |
| --- | --- | --- |
| [`semantic-shores-json`](./semantic-shores-json) | 1,000 properties + 12 agents + 40 search phrases | Coastal real-estate listings. A JSON port of the SemanticShoresDB SQL Server vector-search sample, with vectors removed and JSON-shape stress added. |

## Status

The datasets target NostromoDB's documented SQL syntax. The sample queries
haven't been run end to end yet, so function and array-access spellings may
need minor adjustment to match your build.
